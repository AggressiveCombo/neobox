# Security policy

To report a security problem in Neobox, write to neobox@aggressivecombo.com with the details and, if you can, steps to reproduce. Please do not test against other players' accounts or attack the game servers beyond what is needed to show the problem.

Neobox is run by aggressivecombo, a private individual. The same address is the contact for privacy questions and for the EU Digital Services Act.

The machine-readable contact is at https://neobox.aggressivecombo.com/.well-known/security.txt.
